# ServoTest —— PE5 单舵机测试

> 更新日期：2026-10-30  
> 工程：`ServoTest\ServoTest.uvprojx`  
> 主程序：`ServoTest\servotest_main.c`

## 1. 舵机与接口

当前使用单个 `60 kg·cm`、`270°` PWM 舵机：

| 项目 | 参数 |
|---|---|
| 信号引脚 | `PE5` |
| 定时器通道 | `TIM9_CH1` |
| PWM 周期 | `20 ms`，50 Hz |
| 控制脉宽 | `500-2500 us` |
| 中位 | `1500 us` |

舵机使用独立电源，舵机 GND 与 STM32 GND 必须共地。不要使用 MCU 的
3.3 V 引脚给舵机供电，并确认 5 V 电源能承受舵机堵转峰值电流。

## 2. 三档位置

| 状态 | PE5 |
|---|---:|
| 投递/释放 `DELIVER` | `500 us` |
| 中间位置 `MID` | `1500 us` |
| 物品持有 `HOLD` | `2500 us` |

源码：

```c
#define SERVO_MIN_US          500U
#define SERVO_MID_US          1500U
#define SERVO_MAX_US          2500U

#define SERVO_PE5_DELIVER_US  SERVO_MIN_US
#define SERVO_PE5_HOLD_US     SERVO_MAX_US
```

## 3. 安装舵盘模式

将：

```c
#define SERVO_INSTALL_MODE 1
```

烧录后 PE5 固定输出 `2500 us`，程序不再改变 PWM，用于安装舵盘。

安装完成后：

1. 断电；
2. 把 `SERVO_INSTALL_MODE` 改为 `0`；
3. 重新编译并烧录。

串口输出：

```text
ServoTest: INSTALL MODE PE5=2500 HOLD
```

## 4. 循环测试

`SERVO_INSTALL_MODE = 0` 时，上电先进入 `HOLD`，等待 `2000 ms` 后循环：

```text
DELIVER 500 us
MID 1500 us
HOLD 2500 us
MID 1500 us
```

每个状态保持 `1500 ms`。

串口示例：

```text
ServoTest: state=DELIVER PE5=500 us
ServoTest: state=MID PE5=1500 us
ServoTest: state=HOLD PE5=2500 us
```

## 5. LED

| 状态 | LED |
|---|---|
| `HOLD` 或安装模式 | 红灯常亮 |
| `MID`、`DELIVER` | 绿灯常亮 |

## 1. 测试接口

本测试沿用 Template 中的一路舵机接口：

| 项目 | 配置 |
|---|---|
| 信号引脚 | `PE5` |
| 定时器通道 | `TIM9_CH1` |
| PWM 频率 | `50 Hz` |
| PWM 周期 | `20 ms` |
| 最小脉宽 | `800 us` |
| 中间脉宽 | `1500 us` |
| 最大脉宽 | `1700 us` |

舵机电源应使用独立 5 V 电源，舵机 GND 必须与 STM32 GND 共地。不要直接用
MCU 的 3.3 V 引脚给舵机供电。

当前工程只控制一路舵机信号。如果车上安装了第二个舵机，除非两个舵机信号
线并联到 `PE5`，否则第二路不会被本程序控制。

## 2. 测试动作

上电后舵机先输出 `800 us`，等待 `2000 ms`，然后循环：

```text
800 us
1500 us
1700 us
1500 us
```

每个位置保持 `1500 ms`，之后循环。

## 3. 串口输出

USART1，`PA9`，`19200 8N1`：

```text
== ServoTest: PE5 / TIM9_CH1, 50 Hz ==
ServoTest: range=800..1700 us, start in 2000 ms
ServoTest: pulse=800 us
ServoTest: pulse=1500 us
ServoTest: pulse=1700 us
ServoTest: pulse=1500 us
```

## 4. LED

| 测试位置 | LED |
|---|---|
| `800 us`、`1500 us` | 绿灯常亮 |
| `1700 us` | 红灯常亮 |

## 5. 参数

源码顶部：

```c
#define SERVO_MIN_US            800U
#define SERVO_MID_US            1500U
#define SERVO_MAX_US            1700U

#define SERVO_START_DELAY_MS    2000U
#define SERVO_HOLD_MS           1500U
```

修改 `SERVO_HOLD_MS` 可以调节每个角度停留时间。

如果舵机在两端持续抖动、堵转或发出异响，说明机构或者舵机实际角度范围
小于当前脉宽范围，应立即断电并缩小：

```c
#define SERVO_MIN_US            900U
#define SERVO_MAX_US            1600U
```

不要盲目使用 `500..2500 us`，部分舵机或机构会被顶死。

## 7. 第一次测试

1. 舵机先空载，不要连接会顶死的机构；
2. 核对信号线接 `PE5`；
3. 舵机 5 V、GND 接好，并与主控共地；
4. 烧录后按复位；
5. 观察是否依次到三个位置；
6. 串口角度和实际方向不一定一一对应，以机械结构安全为准；
7. 确认无堵转后再连接实际抛投机构。

## 8. 常见问题

| 现象 | 检查 |
|---|---|
| 舵机完全不动 | PE5 信号、5 V 电源、共地 |
| 一直向一个方向顶死 | 最小/最大脉宽与实际舵机范围不匹配，立即断电 |
| 到达角度后抖动 | 电源电流不足、机械负载过大或脉宽超出范围 |
| 上电后立即快速摆动 | 检查是否烧录了旧工程或 PE5 被其他模块复用 |
| 串口有输出但舵机不动 | MCU 程序已运行，重点查舵机供电和信号线 |

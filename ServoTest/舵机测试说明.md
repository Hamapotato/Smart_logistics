# ServoTest —— PE5 / PE6 双舵机镜像测试

> 更新日期：2026-10-28  
> 工程：`ServoTest\ServoTest.uvprojx`  
> 主程序：`ServoTest\servotest_main.c`

## 1. 舵机接口

两个舵机共用 TIM9 的 50 Hz 时基：

| 舵机 | 信号引脚 | 定时器通道 | 安装方式 |
|---|---|---|---|
| 左舵机 | `PE5` | `TIM9_CH1` | 基准方向 |
| 右舵机 | `PE6` | `TIM9_CH2` | 与 PE5 面对面镜像安装 |

舵机电源使用独立 5 V，舵机 GND 与 STM32 GND 共地。不要用 MCU 的
3.3 V 引脚给舵机供电。

## 2. 镜像状态定义

由于两个舵机面对面安装，同样的机械状态需要相反方向的脉宽：

| 机械状态 | PE5 | PE6 |
|---|---:|---:|
| 物品持有 `HOLD` | `1700 us` | `800 us` |
| 中间位置 `MID` | `1250 us` | `1250 us` |
| 投递/释放 `DELIVER` | `800 us` | `1700 us` |

因此后续业务逻辑应当成对设置：

```text
HOLD    -> PE5 1700, PE6 800
MID     -> PE5 1250, PE6 1250
DELIVER -> PE5 800,  PE6 1700
```

## 3. 安装舵盘模式

源码默认：

```c
#define SERVO_INSTALL_MODE 1
```

烧录后程序只执行一次：

```text
PE5 固定 1700 us
PE6 固定 800 us
```

两者都处于“物品持有”姿态，之后程序不再改变 PWM，便于安装舵盘。

串口会显示：

```text
ServoTest: INSTALL MODE PE5=1700 HOLD, PE6=800 HOLD
```

安装步骤：

1. 烧录安装模式固件；
2. 确认 PE5、PE6 分别到位并保持不动；
3. 在持有姿态下安装两个舵盘；
4. 断电；
5. 把 `SERVO_INSTALL_MODE` 改为 `0`；
6. 重新编译并测试完整状态循环。

## 4. 双舵机循环测试

修改：

```c
#define SERVO_INSTALL_MODE 0
```

上电先进入 `HOLD`，等待 `2000 ms`，然后循环：

```text
DELIVER
MID
HOLD
MID
```

每个状态保持 `1500 ms`。

串口示例：

```text
ServoTest: state=DELIVER PE5=800 us PE6=1700 us
ServoTest: state=MID PE5=1250 us PE6=1250 us
ServoTest: state=HOLD PE5=1700 us PE6=800 us
```

## 5. LED

| 状态 | LED |
|---|---|
| `HOLD` 或安装模式 | 红灯常亮 |
| `MID`、`DELIVER` | 绿灯常亮 |

## 7. 注意事项

- 首次安装舵盘时务必使用 `SERVO_INSTALL_MODE 1`；
- 不要让舵机在机械限位处长时间堵转；
- 如果某一边方向与预期相反，先检查舵盘是否装反，再检查 PE5/PE6 输出；
- PE6 使用 `TIM9_CH2`，不能把 `PE6` 配置成普通 GPIO；
- 两个舵机建议使用独立 5 V 电源，或确认现有 5 V 电源能提供足够峰值电流。

# SpeedTest —— JGB37-520 四轮编码器速度闭环测试

> 适用电机：JGB37-520，330 r/min，减速比 1:30  
> 适用驱动板：幻尔四路编码电机驱动板，地址 `0x34`  
> 工程：`SpeedTest\SpeedTest.uvprojx`

## 1. 测试目标

程序让四个轮子按照指定线速度运行，并读取驱动板内部的编码器累计计数，在 STM32 侧做外环 PI。底层使用 MoveTest 已验证的 `0x33` 四路速度指令，驱动板内部继续做速度闭环。TIM2 以 10 kHz 自由运行，程序用真实采样间隔换算目标增量，避免串口打印或 I2C 耗时造成固定比例误差。

```text
目标线速度
    ↓
按 TIM2 实测采样间隔换算目标脉冲增量
    ↓
读取 0x3C 四路编码器
    ↓
四个轮子分别计算编码器速度误差
    ↓
外环 PI 修正 0x33 速度指令
    ↓
写 0x33 四路速度指令
```

也就是说，`0x33` 是内环，编码器 PI 是外环。若需要先验证 MoveTest 式下发，可以把 `SPEED_USE_OUTER_PI` 设为 `0`。

## 2. 主要参数

都在 `speedtest_main.c` 顶部：

| 宏 | 默认值 | 含义 |
|---|---:|---|
| `SPEED_MODE` | `SPEED_MODE_FRONT` | 测试方向 |
| `SPEED_TARGET_MM_S` | `200` | 底盘平移目标速度，mm/s；原地旋转时表示单轮切向速度 |
| `SPEED_WHEEL_DIAMETER_MM` | `58.0f` | 全向轮直径 |
| `SPEED_ENCODER_CPR` | `1320.0f` | 每输出轴一圈编码器计数 |
| `SPEED_OMNI_TO_WHEEL_FACTOR` | `0.70710678f` | 45° 对角全向轮的底盘速度到单轮速度系数 |
| `SPEED_TICK_MS` | `50` | 标称控制周期，20 Hz；实际间隔由 TIM2 测量 |
| `SPEED_KP` | `1.00f` | 比例增益 |
| `SPEED_KI` | `0.05f` | 积分增益 |
| `SPEED_CMD_LIMIT` | `80` | 0x33 速度指令最大幅值 |
| `SPEED_OUTPUT_ENABLE` | `1` | 1 = 闭环驱动；0 = 只读编码器 |
| `SPEED_USE_OUTER_PI` | `1` | 1 = 编码器外环；0 = 仅目标速度前馈 |
| `SPEED_ENC_STALL_N` | `10` | 连续多少个周期无编码器反馈后触发 `ENC_ERR` |

### 2.1 编码器 CPR

JGB37-520 常见 Hall 编码器为 11 线，按四倍频计数，减速比 1:30：

```text
CPR = 11 × 4 × 30 = 1320 counts/输出轴圈
```

这只是默认值。必须以实际电机和驱动板的计数方式为准。标定方法：

1. 把 `SPEED_OUTPUT_ENABLE` 改为 `0`。
2. 编译烧录，电机不会转。
3. 手动把某个车轮准确旋转一圈。
4. 记录串口 `pos201/pos202/pos203/pos204` 在转圈前后的差值。
5. 该差值就是该轮 `counts/输出轴圈`，填入 `SPEED_ENCODER_CPR`。
6. 恢复 `SPEED_OUTPUT_ENABLE 1`。

## 3. 方向选择

`SPEED_MODE` 可选：

```c
#define SPEED_MODE          SPEED_MODE_FRONT
```

| 宏 | 运动 | 车轮方向 |
|---|---|---|
| `SPEED_MODE_FRONT` | 前进 | 四轮同向 |
| `SPEED_MODE_BACK` | 后退 | 四轮反向 |
| `SPEED_MODE_LEFT` | 左移 | `(+,-,+,-)` |
| `SPEED_MODE_RIGHT` | 右移 | `(-,+,-,+)` |
| `SPEED_MODE_SPIN` | 原地旋转 | `(+,+,-,-)` |

方向表按车身软件电机顺序 `Motor_201..204`：

```text
201=右前  202=右后  203=左后  204=左前
```

驱动板通道与车身顺序的映射已经写在程序中：

```text
CH1=203  CH2=202  CH3=204  CH4=201
```

## 4. 理论速度

前/后/左/右平移时，45° 对角全向轮的单轮线速度约为底盘平移速度的 `1/√2`：

```text
wheel_speed = chassis_speed × 0.70710678
```

如果实测发现机械布置不是标准 45°，只需要修改 `SPEED_OMNI_TO_WHEEL_FACTOR`。

58 mm 轮子周长：

```text
π × 58 = 182.21 mm
```

330 r/min 时理论轮速：

```text
330 / 60 × 182.21 = 1002 mm/s
```

所以第一次测试建议：

```c
#define SPEED_TARGET_MM_S   100
```

确认四个轮子都能稳定转起来后，再测试 `200`、`300`、`500`。

## 5. 串口输出

USART1，`PA9`，`19200 8N1`。每 500 ms 打印：

```text
Speed[FRONT] target=200mm/s rate10=10 | d201=10 d202=10 d203=10 d204=10 | pos=1234,1230,1228,1231 | cmd=10,10,10,10
```

- `rate10`：目标速度对应的每 10 ms 编码器脉冲数
- `d201..d204`：本轮四个轮子的编码器增量
- `pos201..pos204`：四个轮子的累计编码器位置，可用于 CPR 标定
- `cmd`：本轮实际写入 `0x33` 的四路速度指令

如果某个轮子的 `d` 值与目标相差很大：

1. 检查该轮编码器线束；
2. 检查该轮 `SPEED_ENC_SIGN_xxx`；
3. 检查轮子是否被机械卡住；
4. 检查驱动板该路的电机线。

## 6. 调参方法

先架空车，四个轮子离地。

### 第一步：确认方向

选择 `SPEED_MODE_FRONT`，目标速度先设 `100`。四个轮子应同向转动。

如果某个轮子反向，不要先改 PID，先检查：

- 电机 `M+/M-`
- 编码器 A/B
- `SPEED_ENC_SIGN_xxx`

### 第二步：看四轮是否接近目标

稳定后看 `d201..d204` 是否接近 `rate10`。四轮差值应在合理范围内。

### 第三步：调 PI

- 反应慢：增大 `SPEED_KP`
- 稳定但长期有偏差：增大 `SPEED_KI`
- 反复过冲/抖动：减小 `SPEED_KP`，或减小 `SPEED_KI`
- 启动时电压明显下降：降低 `SPEED_CMD_LIMIT` 或目标速度

建议先保持 `KI=0` 调 `KP`，轮速能接近目标后再加入 `KI=0.03~0.08`。

## 7. 常见现象

| 现象 | 排查 |
|---|---|
| 四轮完全不动 | 检查 VM 电池、PF5/PF6、I2C 地址 `0x34`、`SPEED_OUTPUT_ENABLE` |
| 绿灯常亮但 cmd 一直 0 | 目标速度为 0，或输出使能被关闭 |
| 红绿灯交替急闪 | I2C 写驱动板失败，检查总线和供电 |
| 速度持续飙高 | 编码器符号反了，先把对应 `SPEED_ENC_SIGN_xxx` 改成 `-1` |
| 只有一个轮子特别快 | 该轮编码器没有反馈，外环会误以为速度不足；程序现在会显示 `ENC_ERR` 并退回前馈。检查该轮 Hall 线，或先设 `SPEED_USE_OUTER_PI 0` |
| 速度永远达不到目标 | 目标过大、速度指令限幅太小、电池压降或轮子打滑 |
| 四轮速度差异大 | 检查机械阻力、电机方向、编码器计数和单轮 CPR |
| 串口 `d` 值一直是 0 | 编码器没有读到，检查 Hall 线或 `0x3C` |

### 左后轮特别快

左后轮对应：

```text
车身 Motor_203
驱动板 CH1
串口 d203 / pos203
```

如果 `d203` 一直接近 0，但轮子实际在转，说明 CH1 编码器没有反馈。
旧版外环会不断增大 CH1 的速度指令，导致左后轮越来越快。

当前程序加入保护：

- 连续 `SPEED_ENC_STALL_N` 个周期有指令但几乎没有编码器增量；
- 清除该轮积分；
- 把该轮退回目标速度前馈；
- 串口显示 `ENC_ERR`，红灯闪烁。

排查：

1. 先把 `SPEED_USE_OUTER_PI` 设为 `0`；
2. 烧录，确认四轮都能正常持续转动，不再只有左后轮高速；
3. 手动转左后轮，观察串口 `pos203` 是否变化；
4. 不变化则检查左后电机 Hall 编码器 GND/A/B/VCC 插头；
5. 变化但符号相反，把 `SPEED_ENC_SIGN_203` 改成 `-1`。

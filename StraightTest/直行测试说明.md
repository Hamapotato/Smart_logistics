# StraightTest —— 前后双灰阶直线循迹

> 工程：`StraightTest\StraightTest.uvprojx`  
> 使用传感器：前、后两块亚博 `YB-MUX04-2.0`  
> 不使用：左、右八路灰阶

## 1. 数据有效性规则

当前只使用八路模块中的 `L2-L7` 六路，`L1/L8` 强制屏蔽：

```c
#define GREY6_ACTIVE_MASK 0x7E
```

六路数据全白为 `0x00`、全黑为 `0x7E`，两种情况都判为不可信。

前、后亚博模块都统一换算成 `1=黑、0=白` 的黑线掩码：

- I2C 地址 `0x12`；
- 读取数据寄存器 `0x30`；
- 原始数据先反位、循环移一位，再取反；
- 换算后立即与 `0x7E` 相与，只保留 L2-L7；
- 后向模块使用独立 I2C 总线，地址同为 `0x12`，使用同一套换算。

处理方式：

| 前灰阶 | 后灰阶 | 控制 |
|---|---|---|
| 有效 | 有效 | 同时做平移和转弯修正 |
| 有效 | 无效 | 只根据前灰阶做平移修正 |
| 无效 | 有效 | 只根据后灰阶做平移修正 |
| 无效 | 无效 | 停车，不使用任何错误数据 |

## 2. 位姿计算

探头编号按实物从左到右/从前到后排列，仅使用中间六路：

```text
前灰阶：1、8 屏蔽；2 3 4 为左半，5 6 7 为右半
后灰阶：1、8 屏蔽；2 3 4 为左半，5 6 7 为右半
```

平移权重：

```c
前：0 +8 +5 +1 -1 -5 -8 0
后：0 +8 +5 +1 -1 -5 -8 0
```

转弯权重，前后使用相同物理方向：

```c
前/后：0 +8 +5 +1 -1 -5 -8 0
```

于是：

```c
E_LAT = front_lateral + back_lateral;
E_YAW = front_yaw + back_yaw;
```

| 误差 | 物理含义 | 修正 |
|---|---|---|
| `E_LAT` | 左右平移权重的总和 | 左移/右移 |
| `E_YAW` | 左转/右转权重的总和 | 原地转弯 |

这对应实车数据规律：

```text
前1 + 后8
前2 + 后7
前3 + 后6
```

这些组合的左右转弯权重相互抵消，而平移权重同号相加，`E_LAT != 0`，
应平移修正。

```text
前1 + 后1
```

这种组合的平移权重相互抵消，而转弯权重同号相加，`E_YAW != 0`，
应转弯修正。

## 3. 控制量

平移：

```c
vy = E_LAT * STRAIGHT_LAT_K / 8;
vy = clamp(vy, -STRAIGHT_LAT_MAX, +STRAIGHT_LAT_MAX);
vy *= STRAIGHT_LAT_SIGN;
```

转弯：

```c
w = E_YAW * STRAIGHT_YAW_K / 8;
w = clamp(w, -STRAIGHT_YAW_MAX, +STRAIGHT_YAW_MAX);
w *= STRAIGHT_YAW_SIGN;
```

四轮输出：

```c
m201 = STRAIGHT_CRUISE + vy + w;
m202 = STRAIGHT_CRUISE - vy + w;
m203 = STRAIGHT_CRUISE + vy - w;
m204 = STRAIGHT_CRUISE - vy - w;
```

底盘下发仍然使用 MoveTest 的 `0x33` 直接速度方式，不使用编码器速度闭环。

## 4. 默认参数

```c
#define STRAIGHT_CRUISE          10
#define STRAIGHT_TICK_MS         20
#define STRAIGHT_LAT_K           8
#define STRAIGHT_LAT_MAX         2
#define STRAIGHT_LAT_SIGN        (+1)
#define STRAIGHT_YAW_K           8
#define STRAIGHT_YAW_MAX         1
#define STRAIGHT_YAW_SIGN        (+1)
#define STRAIGHT_DEADBAND        2
```

前、后模块都调用同一套 `YB-MUX04` 换算。

## 5. 方向标定

### 5.1 平移方向

如果 `E_LAT` 为正时车向错误方向横移：

```c
STRAIGHT_LAT_SIGN
```

翻转。

### 5.2 转弯方向

如果 `E_YAW` 为正时车头转向错误方向：

```c
STRAIGHT_YAW_SIGN
```

翻转。

当前平移和转弯修正都已启用。`STRAIGHT_YAW_MAX = 1`，转弯修正以小幅度运行。
转弯分量给四个轮子
增加相同大小的变化量：`201/202` 加 `w`，`203/204` 减 `w`，因此纯旋转时
四轮变化量绝对值为 `|w|`，旋转中心保持在车体中心。

## 6. 串口输出

USART1，`PA9`，`19200 8N1`。

```text
Straight: F=FE->01(OK) B=18->18(OK) EF=0 EB=0 lat=0 yaw=0 | vy=0 w=0
```

字段：

- `F/B`：前后灰阶原始值
- `->` 后面的值：统一成 `1=黑、0=白` 后的黑线掩码
- `C`：执行宽边缘线屏蔽后，真正参与修正的掩码
- `OK/--`：该传感器本周期是否可信
- `EF/EB`：统一安装方向后的位置值
- `lat`：平移误差
- `yaw`：方向误差
- `vy/w`：最终写入 `0x33` 的平移和旋转分量

## 7. 测试步骤

1. 打开 `StraightTest\StraightTest.uvprojx`；
2. Rebuild；
3. 把车放在直线起点；
4. 上电，等待 1 秒后自动开始前进；
5. 先观察前2/后7、前3/后6、前4/后5时是否做平移；
6. 再故意让车头偏斜，观察前2/后2时是否做转弯；
7. 如果六路数据为 `0x00` 或 `0x7E`，车应自动停车。

数码管显示前向模块 L2-L7 中识别为黑色的路号，最多显示4路；
全白、读取失败或超过4路黑线时数码管熄灭。

## 8. 注意

- 本程序只初始化前后灰阶，没有使用左右灰阶。
- 前后灰阶其中一路全同数据时，仍允许另一路有效传感器继续工作。
- 两块都无效时立即停车，避免把全黑/全白垃圾值当成黑线。
- `STRAIGHT_LAT_*`、`STRAIGHT_YAW_*` 的符号必须按实车安装方向标定。

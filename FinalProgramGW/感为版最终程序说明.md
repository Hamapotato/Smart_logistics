# FinalProgramGW —— 感为 GW 四灰阶最终程序

> 更新日期：2026-10-28  
> 工程：`FinalProgramGW\FinalProgramGW.uvprojx`  
> 主程序：`FinalProgramGW\final_gw_main.c`

## 1. 来源

本工程基于：

- `FinalProgram` 的完整比赛流程；
- `GWStraightTest` 的感为 GW 灰度读取方式。

保留完整流程：

- `PD12 TCRT5000` 唯一启动；
- `PD10` 红蓝方运行前切换；
- 四方向移动、平移/旋转纠偏；
- 节点停车、BFS、八路红外避障；
- 终点双舵机投递；
- 原路优先返程和动态障碍重规划。

不包含语音模块依赖。

## 2. 灰度硬件与协议

四块均为感为 GW 八路灰度：

| 方向 | 软 I2C 引脚 | 地址 |
|---|---|---|
| 前 | `PB13=SCL, PB14=SDA` | `0x4F` |
| 后 | `PD1=SCL, PD2=SDA` | `0x4F` |
| 左 | `PC8=SCL, PC9=SDA` | `0x4F` |
| 右 | `PC3=SCL, PC2=SDA` | `0x4F` |

初始化：

```c
F_GW_digital_Init();
B_GW_digital_Init();
L_GW_digital_Init();
R_GW_digital_Init();
```

初始化函数会把模块切换到数字开关量模式。之后直接读取：

```c
f_sw_i2c_read_byte(&f_i2c_interface, 0x4F << 1, &raw);
```

感为数字量约定：

```text
1 = 黑色
0 = 白色
```

不需要亚博版本的 `0x30` 数据寄存器，也不需要亚博位序循环移位。

## 3. 六路巡线规则

仍只使用 `L2-L7`：

```c
bits = raw & GREY6_ACTIVE_MASK;   /* 0x7E */
```

停车判据：

```text
23 = 0x06
67 = 0x60
```

平移和旋转权重：

```c
{ 0, +7, +4, +1, -1, -4, -7, 0 }
```

前后方向误差组合：

```c
平移 = 前向横向权重 - 后向横向权重
旋转 = 前向旋转权重 + 后向旋转权重
```

## 4. 启动与队伍选择

| 功能 | 引脚 | 逻辑 |
|---|---|---|
| TCRT5000 启动 | `PD12` | 上拉，空闲高，低电平触发 |
| 红蓝方切换 | `PD10` | 上拉，低电平按下 |

运行前默认红方：

```text
红方：0000
蓝方：1111
```

`PD10` 每按一次在红方与蓝方之间切换，TCRT5000 启动后锁定选择。
启动成功后数码管显示：

```c
#define FINAL_RUN_DISPLAY 1234U
```

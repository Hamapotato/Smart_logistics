# FinalProgramGW —— 感为 GW 四灰阶最终程序

> 更新日期：2026-10-28  
> 工程：`FinalProgramGW\FinalProgramGW.uvprojx`  
> 主程序：`FinalProgramGW\final_gw_main.c`

## 1. 来源

本工程基于：

- `FinalProgram` 的完整比赛流程；
- `GWStraightTest` 的感为 GW 灰度读取方式。

保留完整流程：

- `PD12 TCRT5000` 唯一启动；
- `PD10` 红蓝方运行前切换；
- 四方向移动、平移/旋转纠偏；
- 节点停车、BFS、八路红外避障；
- 终点双舵机投递；
- 原路优先返程和动态障碍重规划。

不包含语音模块依赖。

## 2. 灰度硬件与协议

四块均为感为 GW 八路灰度：

| 方向 | 软 I2C 引脚 | 地址 |
|---|---|---|
| 前 | `PB13=SCL, PB14=SDA` | `0x4F` |
| 后 | `PD1=SCL, PD2=SDA` | `0x4F` |
| 左 | `PC8=SCL, PC9=SDA` | `0x4F` |
| 右 | `PC3=SCL, PC2=SDA` | `0x4F` |

初始化：

```c
F_GW_digital_Init();
B_GW_digital_Init();
L_GW_digital_Init();
R_GW_digital_Init();
```

初始化函数会把模块切换到数字开关量模式。之后直接读取：

```c
f_sw_i2c_read_byte(&f_i2c_interface, 0x4F << 1, &raw);
```

感为数字量约定：

```text
原始 0 = 黑色
原始 1 = 白色
```

不需要亚博版本的 `0x30` 数据寄存器，也不需要亚博位序循环移位。

## 3. 八路巡线规则

感为版本使用完整 `L1-L8`：

```c
bits = (uint8_t)(~raw);   /* 取反后统一为 1 = 黑，0 = 白 */
```

停车判据：

```text
12 = 0x03
23 = 0x06
87 = 0xC0
76 = 0x60
```

平移和旋转权重：

```c
{ +6, +4, +3, +1, -1, -3, -4, -6 }
```

宽线屏蔽恢复为 `123+45` 或 `678+45` 同时为黑时不参与修正。

前后方向误差组合：

```c
平移 = 前向横向权重 - 后向横向权重
旋转 = 前向旋转权重 + 后向旋转权重
```

四个移动方向的误差与修正映射：

| 移动模式 | 平移/纵向误差 | 旋转误差 | 平移符号 | 旋转符号 |
|---|---|---|---:|---:|
| 前进 | 前 - 后 | 前 + 后 | `+1` | `+1` |
| 后退 | 前 - 后 | 前 + 后 | `+1` | `+1` |
| 左移 | 左 + 右 | 左 - 右 | `+1` | `-1` |
| 右移 | 左 + 右 | 左 - 右 | `+1` | `-1` |

代表性八路组合检查：

```text
前1 + 后8 -> 平移 +12，旋转 0
前1 + 后1 -> 平移 0，旋转 +12
前8 + 后1 -> 平移 -12，旋转 0
前8 + 后8 -> 平移 0，旋转 -12

左1 + 右1 -> 纵向 +12，旋转 0
左1 + 右8 -> 纵向 0，旋转 +12
左8 + 右1 -> 纵向 0，旋转 -12
左8 + 右8 -> 纵向 -12，旋转 0
```

### 节点换向出发

车辆停在节点中心时，下一运动方向的侧向灰度可能整排压在节点横线上，
归一化后会出现全黑或全白，被判为无效数据。若立即要求有效灰度才发车，
车辆会一直停在节点上。

程序在每段行程开始的前 `NODE_DEPART_GRACE_TICKS × NODE_TICK_MS`
（默认 `20 × 20ms = 400ms`）内：

- 不使用无效灰度做纠偏；
- 按 BFS 指定的基础方向低速驶出节点；
- 读到有效线后立即恢复平移和旋转纠偏；
- 节点停车检测仍要等 `500ms` 后才武装，不会把起点节点再次判成终点。

四路 GW 灰度读取增加 `3` 次 I2C 重试，单次通信失败不会再立即终止整段行程。

## 4. 启动与队伍选择

| 功能 | 引脚 | 逻辑 |
|---|---|---|
| TCRT5000 启动 | `PD12` | 上拉，空闲高，低电平触发 |
| 红蓝方切换 | `PD10` | 上拉，低电平按下 |

运行前默认红方：

```text
红方：0000
蓝方：1111
```

`PD10` 每按一次在红方与蓝方之间切换，TCRT5000 启动后锁定选择。
启动成功后数码管显示：

```c
#define FINAL_RUN_DISPLAY 1234U
```

## 5. 舵机向投递方向偏移

投递、中间、持物三个位置可以整体向投递方向移动：

```c
#define FINAL_SERVO_TOWARD_DELIVER_US 500U
```

当前基准值：

```c
PE5 投递基准：800 us
PE5 持物基准：1700 us
PE6 投递基准：1700 us
PE6 持物基准：800 us
```

偏移后实际输出：

| 状态 | PE5 | PE6 |
|---|---:|---:|
| 投递 `DELIVER` | `500 us`（原计算值 `300 us`，受下限保护） | `2200 us` |
| 中间 `MID` | `750 us` | `1750 us` |
| 持物 `HOLD` | `1200 us` | `1300 us` |

两个舵机面对面安装，因此同样向“投递方向”靠近时，PE5 脉宽减小，
PE6 脉宽增大。中间值由投递和持物基准自动计算。

需要调整某一端的持物或投递基准时，只改对应的 `*_BASE_US` 宏；
`DELIVER/MID/HOLD` 三个值会一起重新计算。安全范围限制为
`500-2500 us`。

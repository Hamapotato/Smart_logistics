## 0. 本轮修改

本轮把 `FourDirStraightTest` 在右移方向实车验证得到的纠偏参数同步到
`NodeTest`，并将原来的“前进一次后检查红外”改成固定的七个节点任务。

固定任务序列：

```text
直行 -> 停车
右移 -> 停车
直行 -> 停车
右移 -> 停车
直行 -> 停车
左移 -> 停车
后移 -> 停车
```

上电等待 `1000 ms` 后自动开始，执行完第七步并停车后保持锁停，必须复位
才能重新运行。

## 1. 固定任务表

源码中使用任务数组定义顺序：

```c
#define NODE_TASK_COUNT 7U

static const uint8_t NODE_TASK_MODES[NODE_TASK_COUNT] =
{
    NODE_MODE_FORWARD,
    NODE_MODE_RIGHT,
    NODE_MODE_FORWARD,
    NODE_MODE_RIGHT,
    NODE_MODE_FORWARD,
    NODE_MODE_LEFT,
    NODE_MODE_BACK
};
```

| 步骤 | 运动 | 基础速度 |
|---:|---|---|
| 1 | 前进 | `vx=+10` |
| 2 | 右移 | `vy=-10` |
| 3 | 前进 | `vx=+10` |
| 4 | 右移 | `vy=-10` |
| 5 | 前进 | `vx=+10` |
| 6 | 左移 | `vy=+10` |
| 7 | 后退 | `vx=-10` |

每一步都会一直执行到检测到下一节点，随后反向制动并停车。只有上一步
成功停车后才会开始下一步。

## 2. 已同步的实车参数

这些参数与 `FourDirStraightTest` 当前右移实车验证版本一致：

```c
#define NODE_CRUISE          10
#define NODE_TICK_MS         20
#define NODE_START_DELAY_MS  1000

#define NODE_TRACK_LAT_K     8
#define NODE_TRACK_LAT_MAX   2
#define NODE_TRACK_LONG_MAX  2

#define NODE_TRACK_YAW_K     8
#define NODE_TRACK_YAW_MAX   1

#define NODE_TRACK_DEADBAND  2
```

| 参数 | 数值 |
|---|---:|
| 节点间基础速度 `NODE_CRUISE` | `10` |
| 控制周期 `NODE_TICK_MS` | `20 ms` |
| 上电启动延时 `NODE_START_DELAY_MS` | `1000 ms` |
| 平移增益 `NODE_TRACK_LAT_K` | `8` |
| 平移限幅 `NODE_TRACK_LAT_MAX` | `±2` |
| 纵向修正限幅 `NODE_TRACK_LONG_MAX` | `±2` |
| 旋转增益 `NODE_TRACK_YAW_K` | `8` |
| 旋转限幅 `NODE_TRACK_YAW_MAX` | `±1` |
| 死区 `NODE_TRACK_DEADBAND` | `2` |

平移和旋转使用相同权重：

```c
{ 0, +8, +5, +1, -1, -5, -8, 0 }
```

方向符号：

| 修正量 | 前进 | 后退 | 左移 | 右移 |
|---|---:|---:|---:|---:|
| 平移 | `+1` | `+1` | `+1` | `+1` |
| 旋转 | `+1` | `-1` | `-1` | `-1` |

源码中为不同运动方向分别保留了旋转符号：

```c
#define NODE_TRACK_YAW_SIGN  (+1)  /* 前进 */
#define NODE_BACK_YAW_SIGN   (-1)  /* 后退 */
#define NODE_SIDE_YAW_SIGN   (-1)  /* 左移、右移 */
```

## 3. 四块灰度传感器

| 模块 | 引脚 | 统一后的数据方向 |
|---|---|---|
| 前向 | `PB13=SCL`，`PB14=SDA` | 车上左到右 `1..8` |
| 后向 | `PD1=SCL`，`PD2=SDA` | 与 StraightTest 前向换算一致 |
| 左向 | `PC8=SCL`，`PC9=SDA` | 模块换算后再反位，车上从前到后 `1..8` |
| 右向 | `PC3=SCL`，`PC2=SDA` | 车上从前到后 `1..8` |

四块模块均使用：

```text
地址：0x12
数据寄存器：0x30
```

最终统一为 `1=黑、0=白`，并立即应用 `0x7E` 掩码，只保留 L2-L7。

## 4. 行进时使用哪两块传感器

| 运动 | 用于循迹 | 用于节点停车检测 |
|---|---|---|
| 前进 | 前、后 | 左、右 |
| 后退 | 后、前 | 左、右 |
| 左移 | 左、右 | 前、后 |
| 右移 | 右、左 | 前、后 |

用于循迹的两块模块负责平移误差和旋转误差；垂直于运动方向的两块模块
只负责判断是否到达下一节点。

例如右移时：

```text
右、左模块 -> 计算 vx 平移修正和 w 旋转修正
前、后模块 -> 检测 23 或 67，判断是否停车
```

## 5. 纠偏控制

前后方向：

```text
vx = +10（前进）或 -10（后退）
vy = 平移修正
w  = (前旋转误差 - 后旋转误差) -> 旋转修正
```

左右方向：

```text
vy = -10（右移）或 +10（左移）
vx = 纵向平移修正
w  = (左旋转误差 - 右旋转误差) -> 旋转修正
```

四轮混速：

```c
m201 = vx + vy + w;
m202 = vx - vy + w;
m203 = vx + vy - w;
m204 = vx - vy - w;
```

旋转修正对四个轮子的变化量绝对值均为 `|w|`，旋转中心保持在车体中心。

## 6. 数据有效性与宽线屏蔽

- 单块传感器六路全白 `0x00` 或六路全黑 `0x7E` 判为无效；
- 无效模块本周期不参与平移和旋转修正；
- 相邻位状态变化超过 2 次时判为无效；
- L1、L8 始终不参与显示、修正或节点判断。

## 7. 节点停车

每次出发后等待 `500 ms` 再武装节点检测，避免把起点节点再次判成终点。

停车判据：

```c
#define NODE_STOP_LOW_MASK  0x06
#define NODE_STOP_HIGH_MASK 0x60
```

也就是负责节点检测的任意一块模块出现 `23` 全黑或 `67` 全黑，就立即
执行停车，不要求两侧同时检测到。

停车动作：

```c
#define NODE_BRAKE_SPEED 1
#define NODE_BRAKE_MS    400
#define NODE_INERTIA_SETTLE_MS 150
```

1. 按当前运动方向把等效运动矢量取反，四轮目标速度见下表，持续 `400 ms`；
2. 四轮速度全部设为 `0`；
3. 等待 `150 ms` 让惯性衰减；
4. 执行任务表中的下一步。

停车命令不是固定把四轮设为“前进的反向”，而是与 MoveTest 的轮速组合一致：

| 当前运动 | `Motor_201` | `Motor_202` | `Motor_203` | `Motor_204` |
|---|---:|---:|---:|---:|
| 前进 | `-1` | `-1` | `-1` | `-1` |
| 后退 | `+1` | `+1` | `+1` | `+1` |
| 左移 | `-1` | `+1` | `-1` | `+1` |
| 右移 | `+1` | `-1` | `+1` | `-1` |

这四组正好分别是同方向运动轮速 `(±10)` 的完整反向。
如果实车停车时运动趋势仍不对，优先检查：

- `NODE_BRAKE_SPEED` 和 `NODE_BRAKE_MS` 是否足以克服底盘惯性；
- 停车前是否还有较大的平移或旋转纠偏量；
- 驱动板是否真正接收并执行了低速反向指令。

停车后的自动居中修正当前关闭：

```c
#define NODE_POST_STOP_CENTER 0
```

## 8. 红外传感器与旧换向任务

固定七步任务本身不调用红外避障和连续右移分支。源码中保留了
`Node_FrontObstacle()`、`Node_RightShiftForever()` 等函数，方便后续单独
恢复测试，但它们不会进入当前任务流程。

单独测试红外开关和方向逻辑时使用 `IRTest`。

启动：

## 10. LED 与最终状态

- 七步全部完成：红灯常亮，车辆保持停车；
- 中途超时、传感器读取失败或电机 I2C 写入失败：红灯闪烁，
  车辆保持停车；
- 失败后必须复位才能重新运行。

## 11. 实车测试重点

1. 确认每一步都朝指定方向移动；
2. 确认直行、右移、左移、后退都能保持直线；
3. 确认进入下一节点后能刹车，不会因为惯性越过；
4. 确认停车后不会提前执行下一步；
5. 如果某方向越修越偏，只检查该方向的平移或旋转符号；
6. 如果转向修正方向与 FourDirStraightTest 不一致，优先检查
   `NODE_TRACK_YAW_SIGN`、`NODE_BACK_YAW_SIGN` 和
   `NODE_SIDE_YAW_SIGN`。

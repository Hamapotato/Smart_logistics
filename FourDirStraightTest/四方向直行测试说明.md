## 1. 选择测试方向

源码顶部只改这一行：

```c
#define TEST_DIR TEST_DIR_BACK
```

可选项：

| 宏 | 运动方向 | 循迹模块 |
|---|---|---|
| `TEST_DIR_FRONT` | 前进 | 前、后 |
| `TEST_DIR_BACK` | 后退 | 后、前 |
| `TEST_DIR_LEFT` | 左移 | 左、右 |
| `TEST_DIR_RIGHT` | 右移 | 右、左 |

每次只初始化并使用对应方向的两块传感器，另外两块不参与本测试。

## 2. 纠偏开关

平移修正：

```c
#define TEST_TRANSLATE_ENABLE 1
```

旋转修正：

```c
#define TEST_YAW_ENABLE 1
```

分别设为 `0` 可以单独关闭。

## 3. 控制量

```c
#define TEST_SPEED          10
#define TEST_TRANSLATE_K    8
#define TEST_TRANSLATE_MAX  2
#define TEST_YAW_K          8
#define TEST_YAW_MAX        1
#define TEST_DEADBAND       2
```

前后方向：

- 平移修正作用在 `vy`；
- 旋转误差 = 前旋转权重 - 后旋转权重。

左右方向：

- 平移修正作用在 `vx`；
- 旋转误差 = 左旋转权重 - 右旋转权重；
- 左向模块先反位，统一成车上从前到后 `1..8`。

旋转权重：

```c
{ +8, +5, +2, +1, -1, -2, -5, -8 }
```

平移权重与旋转权重相同：

```c
{ +8, +5, +2, +1, -1, -2, -5, -8 }
```

四轮输出：

```c
m201 = vx + vy + w;
m202 = vx - vy + w;
m203 = vx + vy - w;
m204 = vx - vy - w;
```

## 4. 方向符号标定

代码中为四个方向分别保留了平移和旋转符号：

```c
TEST_TRANSLATE_SIGN_FRONT
TEST_TRANSLATE_SIGN_BACK
TEST_TRANSLATE_SIGN_LEFT
TEST_TRANSLATE_SIGN_RIGHT

TEST_YAW_SIGN_FRONT
TEST_YAW_SIGN_BACK
TEST_YAW_SIGN_LEFT
TEST_YAW_SIGN_RIGHT
```

当前值：

| 方向 | 平移符号 | 旋转符号 |
|---|---:|---:|
| 前进 | `+1` | `+1` |
| 后退 | `+1` | `-1` |
| 左移 | `+1` | `-1` |
| 右移 | `+1` | `-1` |

某个方向单独测试时，如果平移或旋转越修越偏，只翻转该方向的对应符号。

## 5. 数据规则

- 四块模块均使用地址 `0x12`、命令 `0x01`；
- 每块使用独立软 I2C 总线；
- 都执行相同的亚博位序换算；
- 全 `0x00`、全 `0xFF` 判无效；
- 保留 `123 + 45`、`678 + 45` 宽边缘线屏蔽。

## 6. 测试步骤

1. 选择 `TEST_DIR`；
2. 设置两个纠偏开关；
3. Rebuild；
4. Download 并复位；
5. 等待 1 秒后车辆自动按选定方向运动；
6. 通过串口观察平移误差、旋转误差、`vx/vy/w`；
7. 逐个方向完成标定。
